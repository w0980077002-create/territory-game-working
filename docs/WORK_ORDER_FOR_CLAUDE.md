# Поручение Claude Code — старт в новом репозитории

**Поставлена задача владельцем:** сделать механически точную игру VIKING VS ROME по его GDD, с обязательным 100%-главным экраном, выбранными элементами TERRITORY, после загрузки — 21 персонажем в трёх папках. В процессе тестов владелец решит изменения. Не выдумывай новые правила вместо него.

Объединить, проверить ожидаемый SHA256 из `docs/ASSETS_AND_21_CHARACTERS.md`, распаковать и создать manifest. Для пиксельного сравнения проверить появление `assets/references/main-screen-100-percent.png` (он ещё не загружен).

Создать `ARCHITECTURE.md`: дерево проекта, схемы TypeScript-сущностей, battle state machine, цикл волн/боссов/фарм, формулы с единицами, лут, редкости, Paper Doll, три класса, skills/runes/merge, модель основного и поддерживающих спутников, 12 основных слотов + крылья, Благословение, Тёмную энергию, артефакты, сезонную и магазинную экономику, таланты, CloudStorage/offline, UI слои, Telegram API, тесты и изоляция от production. Быстро передать владельцу на утверждение.
4. Подготовить точный план этапов с конечным объёмом **всех** систем GDD, ни одну не вычеркивать. Привязать каждый этап к ID из [матрицы 140 проверок](LOOTBORN_FEATURE_CHECKLIST_20261112_RU.md).

## После утверждения архитектуры — живой результат
**Первый вертикальный срез**, где есть настоящая игра, а не набор макетов:
- Главный экран строго как в 100%-эталоне, по позициям и визуальному наполнению.
- Реальный герой, 2 спутника, враги, движение слева направо, бой, HP, урон, криты, способности, движение/реакции/отлеты.
- Четыре волны и пятая — босс с 30-секундным таймером; поражение, повторный фарм и повторный вызов.
- Заряды Рога, настоящий сундук/случайный лут, окно сравнения, «Надеть»/«Распылить», предмет реально появляется на герое и в сетке, CP пересчитывается. **12 основных слотов + отдельно крылья, которые видны за героем и дают % бонусы**.
- x1/x2, Auto, сохранение и восстановление, базовая офлайн-награда.
- Действия всех доступных кнопок подтверждены. Если второстепенный раздел ещё не реализован, честно обозначить в отчёте, а не маскировать готовой кнопкой.

**Дальнейшие этапы:** кузница/Благословение и 6 редкостей → 3 класса и расширение классов → навыки и все руны/merge → система спутников (основной, поддержка, звёзды, пробуждение, коллекция) → таланты → Chaosite, лагерь, шахты, Chaos Ranch → Тёмная энергия, тёмная экипировка, камни → артефакты, реликвии, исследования/библиотека → PvP, гильдии, Ancient Ruins, Hero Tavern, звания/Zenith → сезоны, ивенты, ездовые животные → все категории магазина, фонды, пакеты и региональная экономика → Telegram интеграция → рефералы/Stars только с реальной проверкой на сервере → перенос проверенной Арены → наполнение 21 персонажем и дальнейшие режимы по решениям владельца. **Подробности — в утверждённом дополнении и глубоком аудите; ни одну систему не вырезать. Для каждого модуля зафиксировать source_region/source_date/confidence и не выдавать неизвестные цифры за реальные.** Это порядок доставки, **не сокращение полного ТЗ**. Зависимые компоненты можно реализовывать раньше, когда это необходимо для работающего среза.

## Тесты и приёмка
- Команды: `npm install`, `npm run build`, typecheck и тесты основных формул и граничных состояний. Не обходить ошибки отключением strict.
- Мобильные 320/360/390/430 px, portrait; Android Chrome и Telegram WebView; touch/gesture/safe areas; десктоп 480×854.
- Видеодоказательство настоящего боя, повторного цикла, лута/экипировки, x2/Auto, возврата после reload и офлайн-наград.
- Скрин сравнения с исходным 100%-образцом.
- Тест замены крыльев: отображение **за спиной героя** и правильное применение/снятие % бонусов и пересчёт CP; 12 основных слотов проверяются отдельно.
- Никаких PR/коммитов/деплоя в `territory-game-builde`; текущую игру не отключать.
