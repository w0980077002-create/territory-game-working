## Этап 0 — **первый конкретный результат**

Создать **`ARCHITECTURE.md`** в корне как **внутренний технический план**, сохранить в GitHub и **без ожидания утверждения владельцем сразу перейти к реализации игры**. В документе должны быть:
- Модульная структура TS strict/Vite, React+Canvas/Phaser, Zustand и Telegram WebApp, реализация точной композиции PNG (слои/UI/Canvas).
- Полные типы: игрок, **12 основных вещей + отдельные крылья**, персонажи/анимации, навыки, руны, классы, 1/2/3 слота напарников, сцены, монстры, босс-фазы, реликвии, валюты, магазин, события и сезоны.
- Реальная battle state machine, источники урона/крит/эффект/кулдауны, boss fight, проигрыш/фарм, лут, UI действий, сохранения/повторные выдачи, исходные формулы GDD и список противоречий без самовольного решения.
- Состав 21 персонажа и честный план создания **реальных анимаций** из PNG-мастеров, сессии боя и многослойного мира. Два спутника должны быть видны по эталону; боевые роли по текущей версии оригинала сверять отдельно.
- Проектные конфиги валют, прогресса, редкостей, офлайн, платежей, цен и регионов с `OWNER/GLOBAL/CN/UNVERIFIED`.
- Изолированный хостинг/тестовый URL, разработка без зависимости от production TERRITORY, сборка/CI, миграции данных нового проекта, тесты на телефоне.
- **План полной реализации всех 201 пунктов** с реальными этапами и критериями приёмки; первый этап не вычёркивает остальные.

## Сразу после создания ARCHITECTURE.md — первый действительно играемый этап

- Главный экран «100%» с точными позициями, боковыми кнопками, основным полотном боя и нижней сеткой; **центральная шестиугольная кнопка с перекрещёнными топорами сохраняется в точности, как на PNG, и НЕ заменяется Рогом Трофеев**; не превращать экран в условные карточки.
- Герой, спутники, враги, мини-боссы/боссы **анимированы**, с живыми ударами, баффами, эффектами, HP/смертью/победой, волнами и повтором.
- Лут/сравнение предметов/надеть/распылить, реальные характеристики и 12+крылья, корректное положение крыльев **за спиной**.
- x1/x2, Auto, ручное действие, сохранение и восстановление; реальный UI откликается, не декоративные заглушки.
- Только отдельная тестовая сборка, никаких внешних платежей и затрагивания живой базы TERRITORY.
- Доказательства: ссылка на тест, скрин сравнения с 864×1536, видео настоящего боя, Android/Telegram WebView проверка, что сделано/не сделано.
