# Codex — первая играбельная сборка

URL: https://w0980077002-create.github.io/territory-game-working/
Ветка: `codex-build`. Публикация: `codex-pages`. Одна общая игровая версия для Codex и Claude, доступна по единой ссылке выше.

Запуск: `npm ci`, `npm run dev`. Проверки: `npm test`, `npm run build`.

Реализовано: Canvas-бой с перемещением/атаками/реакциями/смертями, 4 волны и босс 30 секунд, фарм после поражения, Auto/x2, 3 навыка/9 рун, 3 класса, два спутника, 12 вещей и отдельные видимые крылья с процентами, сравнение/экипировка/распыление, Рог с регенерацией, уровни/таланты/Forge/Blessing/реликвия, шахта, награды, тестовая лавка, инвентарь, локальные сохранения/экспорт/импорт и Telegram CloudStorage.

12.11.2026: 16 автоматических проверок; сборка; успешный Pages deploy; HTTP 200 для HTML/JS/CSS/сцены/персонажей. В опубликованной версии в Chrome вручную проверены живой бой, прохождение боссов, получение крыльев, добыча из Рога, экипировка, reload с сохранением.

Ограничения: первая браузерная игровая версия, не полная приёмка. Главная композиция следует зональной карте; художественная точность эталону ещё не достигнута. Анимация персонажей — программная сегментная деформация исходных мастеров, не авторские покадровые наборы. Арена — AI-тренировка; настоящие PvP, гильдии, серверные сезоны и оставшиеся расширенные системы ТЗ ещё не реализованы. Telegram CloudStorage проверен с mock API, не реальным Telegram-клиентом. Реальные платежи отсутствуют. Физический Android/Telegram WebView не проверен; DevTools эмуляция в доступном браузере заблокирована политикой среды. Полный объём docs/IMPLEMENTATION_PLAN.md не отменён.
