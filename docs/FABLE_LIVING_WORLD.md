# Living World (Fable) — что добавлено поверх игры Codex

Ветка-дополнение к `codex-build` по задаче #4. Цикл «4 встречи + босс», баланс, размеры врагов, камера, молния меча и комиксы не менялись. Новых глав нет. Все числа — TEST_ONLY.

## Модули
| Файл | Роль |
|---|---|
| `src/core/world.ts` | Необязательное поле сохранения `player.world` (seed, `lastLeg`, руна, достижения). Старые сохранения читаются, мусор чинится. |
| `src/game/WorldEvents.ts` | План событий по этапу (детерминированный от seed) и одноразовая выдача наград (`settle`). |
| `src/game/WorldDirector.ts` | Режиссёр: остановка у события, карточка выбора, сцены, настроение мира, руны, хуки боя. |
| `src/game/WorldLife.ts` | Живые детали районов: жаровни, флаги, фонари, канаты, рунные камни, жители, вороны, ветер, погода, сияние. |
| `src/game/EnemyTactics.ts` | Честная тактика врагов: прикрытие щитом, комбо, «ловит момент», смена тактики стрелков. |
| `src/game/CompanionBrain.ts` | Гусь (пике по стрелкам) и пёс (заслон, выручка), эмоции и реакции. |
| `src/game/AudioDirector.ts` | Процедурный звук Web Audio: ветер, шаги, музыка трёх настроений, эффекты. Один AudioContext. |
| `src/data/world-variants.ts` | Таблицы: руны, варианты событий (открываются с этапами), достижения, погода. |
| `src/ui/WorldHud.tsx`, `world.css` | Карточка события, кнопка звука, «Летопись» во вкладке «Путь героя». |

## Точки врезки в код Codex
`Battle.ts`: `director.travel/tick/onArrive/onVictory/back/front`, `brain.step/absorb`, `think/absorb/died` в ударах врагов, `audioFrame`. `WorldRenderer.draw` получил необязательный слой неба. `store.ts`: экспорт `rollItem/addLoot`, нормализация `world`. `snapshot.ts`: проверка новых необязательных полей.

## Правила, которые держит код
- Награда события привязана к этапу и волне (`lastLeg`): перезагрузка, пауза, двойное нажатие и x2 не выдают её повторно.
- Auto не отвечает на события. Без ответа событие истекает (7–12 секунд реального времени) и отряд идёт дальше.
- Топоры OFF замораживают мир, таймер события, спутников и звук окружения.
- Тактика врагов не меняет атаку, здоровье, защиту и размеры; каждое действие подписано на экране и имеет ответ игрока.
- В трёх тестах Codex добавлена одна строка: тест отвечает «пройти мимо» на событие первого перехода.
