## Сохранения и экономика

Вход и переход `ENTRY_PAID → INTRO_7` фиксируются одной транзакцией: отдельного сохранения «оплатил, но run ещё нет» не создаётся. Активные состояния — `INTRO_7`, `CHOICE_1..4`, `SEGMENT_1..4`, `FINAL_BOSS`; результат хранит `WIN_PENDING`/`DEFEAT`, `resultId` и `ack`, затем `CLAIMED`. Отсутствие активного run соответствует списку этажей. Сохраняются runId, пара, выбор, история, количество врагов, последний combatId и отдельный полный checkpoint боя.

Награды пройденных участков и заработанные достижения спутников накапливаются в pending. Во время похода кошелёк не пополняется. «Забрать» одной сохраняемой мутацией начисляет pending, предметы, камни и трофеи; только победа босса открывает `max(darkFloor, floor+1)`. При поражении сохраняется добыча уже завершённых участков и заработанные достижения; незавершённый участок обычной добычи не даёт. Это совместимое правило нашей игры, не доказанное по видео правило конкурента.

Нажатия повторно проверяют состояние. combatId защищает от повторного зачёта боя; result acknowledgment — от повторной выдачи. Ошибка localStorage откатывает мутацию; retry не теряет pending. Web Locks оставляют один writer профиля между вкладками, storage events обновляют вторую вкладку. После закрытия первой вкладки право записи переходит второй. Скрытие страницы ставит бой на паузу; возобновление требует явного действия. Косметическая анимация не участвует в наградах.

### Миграция

Старый run `{f,r:1..3,b,acc}` превращается в бесплатное начало нового маршрута на том же этаже. Уже выданные старой версией валюты и вещи остаются у игрока, старый `acc` повторно не выдаётся. Старый encounter этого run сбрасывается; исходный профиль, этаж, инвентарь и входной ресурс не меняются. Старые результаты читаются как уже подтверждённые. Новые checkpoints сохраняют HP, живых/погибших врагов, снаряды, таймер, навыки и координаты, в том числе при временном переходе в другой режим.

### Неопределённые значения

`portalConfig` содержит 1–4★, независимо выбранную численность 9/10/11 и наши биомы. Распределение и рост характеристик — временные внутренние параметры; формула «4★ → определённое число врагов» не утверждается. Одинаковые пары разрешены. Векторы порталов оригинальные; утверждённые герои, спутники и боссы сохранены.

## Воспроизведение

```sh
npm ci
npm test
npm run lint
npm run build
node --import tsx scripts/qa/dark-realm-fixture.ts
npm run dev
# В другом терминале; нужны Chromium и ffmpeg Playwright:
node scripts/qa/realm-cycle.cjs
node scripts/qa/realm-safety.cjs
node scripts/qa/realm-pack.cjs
```

Для записи: `npx playwright install ffmpeg`. Скрипты используют отдельные `testProfile` и не читают сохранение владельца/облако. `BASE_URL` позволяет выбрать локальный сервер; `WIDTH=390` — повторить один размер. CI PR выполняет lint, тесты и сборку. Публикация производится существующим workflow только из `codex-build`; этот PR сам её не запускает.
