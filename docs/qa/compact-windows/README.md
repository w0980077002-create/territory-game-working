# Основные окна мобильной RPG

База сравнения: `codex-build`, коммит `8e366b7`. Скриншоты сняты в Chromium с изолированным профилем `?hero=windows-qa`, без доступа к прогрессу владельца. На каждом сравнении слева исходная версия, справа новая; размер viewport одинаковый, масштаб изображения не менялся. Проверка физического Telegram Android **не проводилась**.

## Изменения

- `DialogShell`: фиксированная шапка и ограниченная высотой WebView рабочая область для Царства, Тёмной энергии, спутников, реликвий и гавани. Локальная прокрутка каталогов; общая страница не растёт. Уведомления не сдвигают содержимое.
- `CardDialog`: самостоятельная карточка в нативном верхнем слое браузера. Затемнение, собственная прокрутка, закреплённые действия, Escape/крестик, блокировка фона и возврат фокуса. Каталог остаётся смонтированным.
- Царство: ресурс, оформление этажа, выбор этажей, три комнаты, три благословения и закреплённый вызов. Награды/правила и результат похода открываются отдельно.
- Тёмная энергия: герой и 12 доступных целей по 44 px; склад на пять колонок сразу под экипировкой. Фильтр независим от просмотра надетого слота. Предметы и сравнение открываются поверх склада: две колонки от 375 px, переключение «Новое / Надето» на узком экране; текущий и следующий бонус усиления, цвет разницы. Разбор и сводка комплекта вынесены в отдельные карточки.
- Спутники: компактная активная пара, существующий бонус дружины, каталог на четыре колонки. Отдельная карточка с вкладками уровня, звёзд, талантов и пробуждения; призыв в самостоятельном окне. Эволюция и боевая ветвь сохранены во вкладке уровня.
- Реликвии: каталог на четыре колонки; эффект, следующий уровень, материалы и закреплённая кнопка в отдельной карточке.
- Гавань: одна сцена, по одному переходу к каждому разделу; убраны доказанные дубли кузницы, рюкзака, спутников и реликвий. Кузница разделена на вкладки. Верфь, добыча и стоимость её действий сохранены.

Изменений в `core`, `dark/actions`, `dark/rules`, боевом движке, сохранениях, формулах, наградах, ценах, основных слотах/крыльях и TERRITORY нет. В карточках показаны только характеристики, существующие в модели.

## Проверка

`npm run test:windows` проверяет 320×640, 360×740, 390×780 и 430×932, дополнительно каждую ширину при высоте 568 с верхним отступом Telegram 26 px и нижним 24 px.

Подтверждено через реальные кнопки:

- Открытие, закрытие и повторный вход во все пять окон; отсутствие общей и горизонтальной прокрутки.
- Выбор этажа и благословения; просмотр правил; доступность всех 12 слотов.
- Полный склад на 60 вещей и пустой склад; фильтр; независимая прокрутка; сохранение позиции после закрытия карточки.
- Надевание, усиление, защита, снятие, подтверждение разбора; сравнение, длинный заголовок, доступность закреплённых действий.
- Вкладки спутника, повышение уровня, недоступное пробуждение, призыв с однократным расходом печати.
- Усиление реликвии и заблокированное действие при нехватке золота.
- Переходы гавани, вкладки кузницы, верфь и возврат.
- Reload сохраняет золото, реликвию, спутников и данные Saga. Двойное нажатие вызова списывает только 5 Хаосита; оплаченный поход восстанавливается.

В 20 сочетаниях окна и ширины внешний и горизонтальный overflow равен нулю. Высота видимой области склада: 185 / 277 / 247 / 337 px соответственно; на всех размерах видны минимум две строки. Численные результаты: [JSON](layout-results.json).

`npm test`: 203 теста прошли, включая одноразовые награды трёх комнат, повторные прохождения, сохранения, спутников и реликвии. `npm run lint`: ESLint для изменённых TSX-компонентов и правил React Hooks. `npm run build`: TypeScript и Vite. `python3 scripts/validate_handoff.py`: исходный арт и регламент сохранены. Существующее предупреждение Vite о JS-бандле более 500 KB остаётся.

Для PR добавлен CI `RPG windows · mobile layout and gameplay`: lint → игровые тесты → build → Chromium → мобильные сценарии, со скриншотами в артефакте `mobile-window-screenshots`. Публикация и merge этим изменением не выполняются.
