# Зелья и эликсиры Арены — интеграция утверждённой графики (Issue #81, комментарий 7179993635)

Источник: архив владельца `VVR_elixirs.zip` (Drive), 20 WebP 256×256 + `mapping.csv`, `qa.txt`, `integration_claude.txt`.

## Итог
- Подключено иконок: **20 из 20** (`public/art/elixirs/*.webp`, единый каталог `elixirArt` в `src/arena/potion.ts`).
- Реально работающих расходников: **1 из 20** — «Сердце Вальгаллы» = существующее зелье лечения (`consumables.potion`, ID `potion`, покупка `arena-potion`).
  Эффект, цена (формула `healingPotion.cost`), перезарядка 4 с и лечение 45% HP — без изменений; изменено только название и иконка.
- Остальные 19 — только графическая привязка в каталоге: в Лавке, Рюкзаке и Арене не показываются, не покупаются и не хранятся.

## Где отображается
- Лавка: отдельный раздел «Зелья и эликсиры» (категория `elixirs`); иконка раздела — Сердце Вальгаллы.
- Рюкзак → «Расходники»: стопка с иконкой, названием, описанием и количеством.
- Арена: пояс «Эликсиры и зелья» (иконка + количество + откат) и «Описание расходников».
- Единый источник иконки: `consumables.potion.icon = elixirIcon('valhalla-heart')`, `Icon` рисует `elixir-*` из `public/art/elixirs/`.

## QA графики
Архив: 20/20 WebP lossless 256×256 RGBA (проверено). Найденные дефекты альфа-маски (маска строилась по яркости):
1. тёмная полупрозрачная «подложка» вокруг свечения с прямым срезом по краю ячейки исходного листа;
2. отдельные точки мусора вне объекта (до 428 px у Хитрости Локи);
3. полупрозрачные «дыры» внутри тёмных частей флаконов.

Исправлен **только альфа-канал** (RGB совпадает пиксель в пиксель, проверено), перекодирование lossless WebP: бесцветный тёмный остаток подложки погашен, цветное свечение сохранено; замкнутые дыры внутри плотного силуэта заполнены; мусор удалён; край ячейки смягчён на 10 px. Художественный рисунок не изменялся. До/после на светлом, тёмном и ореховом фоне: `alpha-cmpA.webp`, `alpha-cmpB.webp`.
