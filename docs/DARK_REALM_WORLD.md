# Подземный мир Царства тьмы

Источник: [мастер-ТЗ №12](https://docs.google.com/document/d/1g6TCeaVqXsqn5zIdkcnR_uIbOboKzCDeG0TOagvb0eU/edit), разделы 07, 09, 20, 21, 41–44, и последнее поручение владельца: **закрытая подземная пещера**. Архивный референс: [сентябрьская последовательность «Пещера → победа → Тёмная энергия»](https://docs.google.com/document/d/12_ipJosnOOwCouRPAh8F8QvTXDQEmRUYLQVLwfVZp0g/edit). Архив используется для игрового пути; весь новый арт создан отдельно для Викингов.

Три комнаты: кристальные Врата мучений; цепной зал стража с подземными водопадами; багровое драконье святилище владыки. Нет неба, затмения или открытого горизонта.

`src/dark/RealmWorld.ts` рисует отдельную визуальную конфигурацию внутри обычного `Battle.draw()`. Дальний рисунок, объекты на разных глубинах, дорога и ближние кристаллы следуют общей камере. Фон не циклическая панорама: композиции имеют адреса на пути, подходы различаются по этажам. Повторяется только мощение дороги.

Подвесные фонари, свечение жаровен, подземные водопады, частицы и низкая дымка используют `Battle.clock`. Свет усиливается к арене; существующие сильные удары подсвечивают трещины. Появление босса раскрывает рунную печать за его силуэтом. Победное кольцо занимает существующий интервал победы: выдача добычи не задерживается. Ни одна функция рендера не меняет сохранение, урон, баланс или игровой RNG.

## Арт

`public/art/dark/` содержит три оригинальные иллюстрации, созданные для этой задачи и упакованные ImageMagick в WebP без изменения композиции:

| Файл | Размер | Содержимое |
| --- | --- | --- |
| chambers.webp | 887×1774 | три разных подземных зала, вертикальный атлас |
| props.webp | 887×1774 | шесть отдельных прозрачных объектов |
| road.webp | 1774×887 | прозрачная каменная дорога с объёмным обрывом |

Общий размер загрузки около 1.8 MiB, декодированный объём около 19 MiB. Все изображения прогреваются вместе с боевой сценой. Нет фильтра/тонировки поверх персонажей, CSS blur или создания промежуточных полотен каждый кадр. При снижении качества остаются все художественные слои, уменьшаются только эффекты; reduced motion фиксирует подвесы и отключает дымку/частицы.

## Проверка

- `npm test` и `npm run build`.
- `node --import tsx scripts/qa/dark-realm-fixture.ts`
- При запущенном `npm run dev`: `node scripts/qa/dark-realm.cjs` (Playwright + Chromium).

Браузерный сценарий использует изолированный профиль, проходит настоящий бой без изменения HP/урона, проверяет три комнаты, награды, следующий этаж, неизменность HUD, отсутствие прокрутки, паузу и reload на 320/360/390/430 px. Кадры и JSON-отчёт сохраняются в `.tmp/qa/`. Физический Telegram Android WebView этим сценарием не проверяется.

Проверено 17.11.2026: 203/203 теста, production build, полный вышеописанный Chromium-цикл на всех четырёх ширинах без JS/HTTP-ошибок. Сравнены настоящие кадры PvE и всех трёх комнат. Дополнительно измерена отрисовка на 390 px с CPU throttle ×4: медиана около 34 ms; это программная проверка, не физический Android. Физический Telegram WebView не проверен.
