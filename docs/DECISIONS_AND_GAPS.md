## C. Данные, которых нет и которые запрещено выдумывать

- Полный актуальный **состав каждого международного Special Pack**, региональные персональные скидки, VIP бонусы/уровни.
- Шансы дропа, pity, стоимость рангов/крыльев для каждого предмета глобального 2026 сервера.
- Два наименования **обычных основных** слотов экипировки, если их нельзя однозначно прочитать с исходного клиента.
- Слоты пассивных навыков и конкретная боевая расстановка спутников в текущей международной версии, если данные конфликтуют с 100%-изображением.
- Непосредственно не подтверждённые ограничения возраста сервера/сезона для международного Lootborn.
- Готовые боевые анимации для 21 авторского персонажа: **их нет в архиве**, их нужно создать.

**Правило реализации:** неизвестное поле получает `UNVERIFIED` + источник/дату; **сам экран и утверждённые функции при этом не выбрасываются**. Конкретную цифру нельзя молча подменять оценкой.
