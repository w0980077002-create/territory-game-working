# Интервью и идеи владельца — «Викинги и римляне»

**Единое место для всех идей из интервью.** Создано 13.11.2026. Рабочая ветка новой игры: `codex-build`.

## Как пользоваться
- Здесь хранятся решения и идеи **только новой игры «Викинги и римляне» (VIKING VS ROME: LOOTBORN SAGA)**. Старая «Территория» — отдельная игра, её код и данные не затрагивать.
- Каждое следующее интервью / новая идея владельца пополняет **эту папку**, а не разбрасывается по случайным ТЗ, чатам и репозиториям.
- Одна идея = запись с **датой, статусом, сутью, условиями и ссылкой на связанные решения**. Не стирать предыдущие версии беседы: изменения решений отражать явно.
- Статусы: **УТВЕРЖДЕНО** (решение владельца), **НА ПОТОМ** (одобрена идея, но не запускать сейчас), **ОБСУЖДАЛИ / УТОЧНИТЬ** (нет окончательного решения), **ЗАМЕНЕНО** (более позднее решение имеет приоритет).
- Не выдавать предложение помощника за решение владельца. Не считать записи здесь командой немедленно реализовать всё: очередность определяет владелец и `DEVELOPMENT_WORKFLOW.md`.
- Перед новым заданием по затронутой механике Codex/Claude сверяются с этой папкой. Не создавать вторую игру и не разрушать проверенные механики.
- **Не называть новую игру «1.0»**: принятое название — «Викинги и римляне».
