# Верфь кораблей — тестовый прототип VIKING VS ROME
Утверждение владельца: корабли должны добывать собственную внутриигровую валюту (красные алмазы как первый пример). Функция реализуется только в изолированных Викингах. НЕ связана с живой TERRITORY, COC, USDT или Telegram Stars.
## Тестовые параметры
- Бесплатный первый драккар в каждом новом и старом профиле.
- 1 тестовый красный алмаз/час за уровень корабля; максимум 3 драккара по 5 уровней; накопление до 12 часов.
- Строительство корабля №2 за 500 золота, №3 за 1000 золота; улучшение следующего уровня за 300 * уровень^2 золота.
- Добыча поступает в кошелёк только после нажатия Забрать. Двойное нажатие ничего не удваивает. Строительство/улучшение не увеличивают добычу за прошлые часы.
- Старый save version 1 читается без изменения, новые поля optional. Некорректный save — штатный recovery вместо сброса прогресса.
- Условия и стоимость видны каждому игроку, формулы одинаковые для обычных и тестовых профилей.
## Ограничение
Клиентский clock и localStorage можно подменить. Это только TEST_ONLY прототип без права вывода, продажи, обмена на ценные товары или обещаний денежной стоимости. Для реальной премиальной валюты: серверное время, отдельный журнал начислений, идемпотентность, транзакционная обработка, проверка владения кораблём и прозрачный учёт без привилегированных ботов.
## UI
Вход из существующей Северной гавани. Главное изображение 864x1536, центральные топоры, 12+1, бои, спутники и все существующие данные не изменяются. Художественный вид кораблей в собственной мультяшной стилистике — отдельная задача, после игрового прототипа и проверки.
