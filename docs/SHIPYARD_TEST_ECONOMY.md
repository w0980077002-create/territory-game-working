# Верфь кораблей — игровая система VIKING VS ROME
Утверждение владельца: корабли должны добывать собственную внутриигровую валюту (красные алмазы как первый пример). Функция реализуется только в изолированных Викингах. НЕ связана с живой TERRITORY, COC, USDT или Telegram Stars.
## Игровые параметры первого баланса
- Бесплатный первый драккар в каждом новом и старом профиле.
- 1 красный алмаз/час за уровень корабля; максимум 3 драккара по 5 уровней; накопление до 12 часов.
- Строительство корабля №2 за 500 золота, №3 за 1000 золота; улучшение следующего уровня за 300 * уровень^2 золота.
- Добыча поступает в кошелёк только после нажатия Забрать. Двойное нажатие ничего не удваивает. Строительство/улучшение не увеличивают добычу за прошлые часы.
- Старый save version 1 читается без изменения, новые поля optional. Некорректный save — штатный recovery вместо сброса прогресса.
- Условия и стоимость видны каждому игроку, формулы одинаковые для всех игровых профилей.
## Ограничение
Клиентский clock и localStorage можно подменить. Красные алмазы сейчас являются только внутриигровой валютой, без вывода или обмена на реальные деньги. Игрок не видит служебных обозначений разработки. Для реальной премиальной валюты: серверное время, отдельный журнал начислений, идемпотентность, транзакционная обработка, проверка владения кораблём и прозрачный учёт без привилегированных ботов.
## UI
Вход из существующей Северной гавани. Главное изображение 864x1536, центральные топоры, 12+1, бои, спутники и все существующие данные не изменяются. Художественный вид кораблей в собственной мультяшной стилистике — отдельная задача, после проверки игровой механики.
