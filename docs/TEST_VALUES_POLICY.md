# Правило разработки: временные значения без лишнего согласования с владельцем

**Историческое решение от 12.11.2026, уточнено 19.11.2026 для Solo 1.1:** существенные изменения утверждённых цен, шансов, наград, экономики и механик согласовываются пакетом в текущем Issue. В пределах согласованного тестового задания технические детали, примерные цены, вероятности и формулы для тестовой сборки исполнитель выбирает самостоятельно, не перекладывая их на владельца. Профессиональные решения по первоначальному тестовому балансу принимает исполнители (Codex и Claude) самостоятельно. После запуска владелец по реальной игре сообщает, что нравится и что изменить.

## Уже заданные временные значения

[config/test-balance.v1.json](../config/test-balance.v1.json) — готовые **настоящие тестовые значения**, а не пустая таблица: начальные ресурсы/статы, прогрессия, шанс 9 качеств добычи (сумма весов 100%), тестовые крылья с процентами, цены кузницы, награды, лимиты, таймеры и **10 тестовых наборов**.

**Все значения в этом JSON — предложения для теста, а не заявленные оригинальные данные Lootborn Warriors.** Исполнитель может корректировать неподтверждённые пробные значения в пределах согласованного задания, не заставляя владельца обсуждать каждую цифру; выход за согласованные границы — отдельное решение. Встроить загрузку конфигурации в работающий код, а не оставлять JSON неиспользуемым.

## Что Codex и Claude решают самостоятельно

- Временные цены, шансы, содержимое тестовых наборов, награды, затраты ресурсов, коэффициенты и таймеры, только в пределах согласованной задачи, если нет более позднего точного утверждения владельца.
- Техническую архитектуру и порядок реализации, защиту от ошибок, тесты, производительность, внутриигровые состояния. Сервер не добавлять в текущем пакете.
- Подбор временных чисел по результатам реальной игры, чтобы сохранялась интересная прогрессия; указать существенные правки в существующем PR без отдельного отчёта.

## Что нельзя заменять временными значениями

- Утверждённый главный экран и центральная кнопка с топорами, 12 основных слотов + отдельные крылья, собственные персонажи и общий игровой объём.
- **Реальные деньги, Telegram Stars, настоящие платёжные цены, VIP за реальные деньги**: конфиг содержит только тестовые токены, не подключать реальную оплату без отдельной реализации безопасности и явного одобрения владельца.
- Действующую TERRITORY, её Supabase, аккаунты, покупки и прогресс.
- Не выдавать тестовые значения за проверенные цены, шансы и награды международной Lootborn Warriors.

## Критерий готовности

Игра должна **работать с разумными приблизительными числами**, а не зависеть от того, знает ли владелец точную стоимость или процент. Рядом с технической документацией достаточно отметки TEST_VALUE. **Не требовать согласования каждого коэффициента.** Согласовывать существенные изменения утверждённых механик, баланса, экономики и визуального эталона; реальные платежи — только отдельным решением.

Конкретный состав тестового конфига можно редактировать без изменения логики экранов. Это действующее правило для работающей общей игры в `codex-build`: приложение уже есть, повторно создавать его не требуется.
