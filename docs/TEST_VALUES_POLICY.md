# Правило разработки: временные значения без лишнего согласования с владельцем

**Решение владельца от 12.11.2026:** он начинающий вайбкодер, не обязан выбирать проценты, цены, формулы и технические детали. Профессиональные решения по первоначальному тестовому балансу принимает исполнитель (Claude Code) самостоятельно. После запуска владелец по реальной игре сообщает, что нравится и что изменить.

## Уже заданные временные значения

[config/test-balance.v1.json](../config/test-balance.v1.json) — готовые **настоящие тестовые значения**, а не пустая таблица: начальные ресурсы/статы, прогрессия, шанс 9 качеств добычи (сумма весов 100%), тестовые крылья с процентами, цены кузницы, награды, лимиты, таймеры и **10 тестовых наборов**.

**Все значения в этом JSON — предложения для теста, а не заявленные оригинальные данные Lootborn Warriors.** Исполнитель может корректировать их сам по результатам тестов, не заставляя владельца обсуждать каждую цифру. Встроить загрузку конфигурации в работающий код, а не оставлять JSON неиспользуемым.

## Что Claude решает самостоятельно

- Временные цены, шансы, содержимое тестовых наборов, награды, затраты ресурсов, коэффициенты и таймеры, если нет более позднего точного утверждения владельца.
- Техническую архитектуру и порядок реализации, защиту от ошибок, тесты, производительность, серверные таблицы и внутриигровые состояния.
- Подбор временных чисел по результатам реальной игры, чтобы сохранялась интересная прогрессия; вести changelog тестовых правок.

## Что нельзя заменять временными значениями

- Утверждённый главный экран и центральная кнопка с топорами, 12 основных слотов + отдельные крылья, собственные персонажи и общий игровой объём.
- **Реальные деньги, Telegram Stars, настоящие платёжные цены, VIP за реальные деньги**: конфиг содержит только тестовые токены, не подключать реальную оплату без отдельной реализации безопасности и явного одобрения владельца.
- Действующую TERRITORY, её Supabase, аккаунты, покупки и прогресс.
- Не выдавать тестовые значения за проверенные цены, шансы и награды международной Lootborn Warriors.

## Критерий готовности

Игра должна **работать с разумными приблизительными числами**, а не зависеть от того, знает ли владелец точную стоимость или процент. Рядом с технической документацией достаточно отметки TEST_VALUE. **Не спрашивать владельца о каждом коэффициенте.** Спрашивать его только если надо изменить ранее утверждённую концепцию/визуальный эталон или реально включить платежи.

Конкретный состав тестового конфига можно редактировать без изменения логики экранов. Это подготовка к Claude Code; пока самого приложения в репозитории ещё нет.
