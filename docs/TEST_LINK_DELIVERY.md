# Как владелец тестирует обновления единой игры

**Текущее состояние 12.11.2026:** игровая сборка уже опубликована из `codex-build` по https://w0980077002-create.github.io/territory-game-working/ . Это общий адрес для следующих задач Codex и Claude.

## Порядок выпуска и проверки обновлений

1. Продолжать уже работающую игру из актуального `codex-build`. Сборка GitHub Pages настроена; она обновляет общую ссылку после изменений в этой ветке. Не создавать отдельный постоянный хостинг и не трогать живую TERRITORY.
2. Выдать владельцу **один настоящий постоянный HTTPS-адрес тестовой игры**, доступный с Android. Следующие версии публиковать **по тому же адресу**, без необходимости скачивать ZIP, запускать HTML из архива или искать новую ссылку.
3. Подключить вход из Telegram Mini App к этому HTTPS-адресу в отдельном тестовом боте/точке входа, когда готовы необходимые настройки. До готовности Telegram-входа предоставлять честно обозначенную **браузерную тестовую ссылку**, а не утверждать, что тест в Telegram уже пройден.
4. При каждой значимой сдаче указывать живую ссылку, коммит и коротко — что реально изменилось и какие существенные ограничения остались. Не требовать обязательного видео, коллажа или длинного отчёта; зелёный CI сам по себе не доказывает качество игры.
5. Протестировать экран на 320/360/390/430 px, безопасные зоны, сохранение при обновлении и боевой цикл. **Фактический Android Telegram WebView** отмечать проверенным только после подтверждённого теста, не автоматически.
6. Реальные платежи/Stars, коммерческие цены и публичный релиз **не включать**; только тестовые токены. Никогда не использовать действующие данные TERRITORY.

## Когда нужен владелец

**Не спрашивать владельца о выборе хостинга, архитектуре и тестовых процентах.** Использовать уже работающую публикацию. Если действительно нужны дополнительные права, коротко назвать одно необходимое действие, не просить секретных токенов в чате.

**Успешная приёмка:** владелец открыл стабильную ссылку на своём телефоне, увидел утверждённый по композиции экран со **своими персонажами**, смог сам поиграть и дать замечания. Фактическая приёмка обновления — после живой проверки владельцем, а не при загрузке документов.
