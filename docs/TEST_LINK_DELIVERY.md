# Как владелец увидит работу Claude — обязательный порядок

**Текущее состояние 12.11.2026:** приложения, развёртывания и игровой ссылки ещё нет. GitHub Actions `preflight` проверяет только исходные материалы, не игру.

## Обязательный результат этапа #2

1. В начале программирования настроить **отдельное тестовое окружение** для НОВОЙ игры и автоматическую сборку/развёртывание. Хостинг выбрать технически подходящий (Cloudflare Pages, Vercel или эквивалент), **не трогать действующую TERRITORY**. GitHub Pages в этом репозитории сейчас не включён; не обещать ссылку без реального деплоя.
2. Выдать владельцу **один настоящий постоянный HTTPS-адрес тестовой игры**, доступный с Android. Следующие версии публиковать **по тому же адресу**, без необходимости скачивать ZIP, запускать HTML из архива или искать новую ссылку.
3. Подключить вход из Telegram Mini App к этому HTTPS-адресу в отдельном тестовом боте/точке входа, когда готовы необходимые настройки. До готовности Telegram-входа предоставлять честно обозначенную **браузерную тестовую ссылку**, а не утверждать, что тест в Telegram уже пройден.
4. При каждой значимой сдаче указывать: **кликабельный URL**, GitHub commit/PR, какие кнопки/механики РЕАЛЬНО работают, что только планируется, мобильный скрин/видео и результаты проверки. Не приравнивать сборку, статичный мок или зелёный CI к работающей игре.
5. Протестировать экран на 320/360/390/430 px, безопасные зоны, сохранение при обновлении и боевой цикл. **Фактический Android Telegram WebView** отмечать проверенным только после подтверждённого теста, не автоматически.
6. Реальные платежи/Stars, коммерческие цены и публичный релиз **не включать**; только тестовые токены. Никогда не использовать действующие данные TERRITORY.

## Когда нужен владелец

**Не спрашивать его о выборе облака, архитектуре, ценах или процентах.** Claude подбирает и реализует технический вариант самостоятельно. Если нет прав на создание отдельного хостинга или привязку нового тестового Telegram-бота, сформулировать **одно конкретное действие по выдаче доступа**, без просьбы передавать секретные токены в чат. Пока доступа нет, разработку и тесты продолжать.

**Успешная приёмка:** владелец открыл стабильную ссылку на своём телефоне, увидел утверждённый по композиции экран со **своими персонажами**, смог сам поиграть и дать замечания. Конец этапа #2 — только после живой проверки, а не при загрузке документов.
