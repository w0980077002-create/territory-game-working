В оценочной таблице пустое поле означает отсутствие доказанного значения или применимого игрового правила. Ожидание в попытках приведено для источников с известными шансами. Переход к минутам требует наблюдаемого времени маршрута. Рыночный ориентир имеет отдельную единицу и основание. [Оценочная таблица](tables/valuation.csv)

В каталоге ID экземпляра и ID шаблона отделены. Снимки однотипных процедурных предметов вычислены на уровне 25. Вероятности по благословению 1 описывают бросок базовой редкости. Для первого трофея, форсированной редкости, бонуса набора и других специализированных источников действует соответствующий маршрут. Среднее ожидание при независимом шансе `p` составляет `1/p` попыток, стоимость = `стоимость попытки/p`. Например, шанс цветного камня 60% и конкретного типа 1/6 дают 10% на тип в повторном финале, около 10 финалов и 50 Хаосита только по этому источнику. Синтез одного камня 10-го уровня требует 19 683 камня 1-го уровня при отсутствии готовых старших камней. Для розничного случайного камня целевой цвет стоит в среднем 180 самоцветов до любого синтеза. Пороговые бонусы, гарантии и комбинированные дропы требуют своей модели, простой геометрический ряд здесь не применим.
