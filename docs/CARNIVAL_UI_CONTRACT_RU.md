# Карнавал VIKING VS ROME — контракт для Claude

## Размещение

Вход «Семидневный карнавал» внутри действующего окна «События» (маршрут `events`, компонент `SeasonRewards` в `src/ui/EventRewards.tsx`). Показывать праздничный значок во время события. Между событиями в этом же окне доступны дата следующего старта, итоги текущего месяца при наличии и выдача ранее заработанных призов. Семь вертикальных вкладок, таймер и шесть призов на общей шкале. Открытие по явному действию игрока, закрытие возвращает в «События». Визуал, компоновка и оригинальный арт в зоне Claude. Для ориентира по функциональности смотреть 00:09–00:23. [Исходное видео](https://drive.google.com/file/d/1QxaMsmpkzNlR1HzcGmVBtQw-aeN3D8Vw/view)

## Чтение состояния

```tsx
import {useGame, claimCarnivalReward} from '../core/store';
import {carnivalView, type CarnivalView} from '../saga/carnival';

const p = useGame(state => state.p);
const event: CarnivalView = carnivalView(p, now); // now в миллисекундах
```

- При открытом окне обновлять `now` раз в секунду и сразу при возврате во вкладку. `phase` даёт `active` или `between`. `remainingMs` содержит время до конца во время события. `nextStartAt` содержит абсолютную дату следующего открытия UTC. При `clockBlocked` показывать «Проверьте дату и время устройства», таймер скрыть. Уже заработанные призы доступны.
- `period` содержит текущий календарный период или его итоги, если месяц продолжается после 7-го числа. Может быть `null`. `past` содержит предыдущие периоды с оставшимися призами, включая частично выданные заряды. Период исчезает из списка `past` после получения последнего приза. `hasClaimable` можно использовать для индикатора в окне событий.
- `period.id` имеет формат `YYYY-MM`. `startAt`, `endAt` и `days[].unlockAt` — Unix-время в миллисекундах. `days[].day` — число от 1 до 7. Вкладки доступны для просмотра сразу, `unlocked=false` означает, что прогресс ещё закрыт. При первом открытии выбирать текущий доступный день, далее сохранять выбор игрока до смены периода.
- Для задания показывать `primary.text`, `primary.progress / primary.target`, приз и `points`. Если есть `alternative`, показать второй вариант с его собственным счётчиком и переходом. Достаточно выполнить любой один вариант. `acceptsProgress` управляет переходами к игровым действиям. Задание, выполненное после открытия дня, добавляет очки автоматически в момент сохранения. Кнопка «Забрать» выдаёт предметы или ресурсы.
- `period.points` может быть от 0 до `maxPoints` (700). Полностью заполненная шкала соответствует `targetPoints` (600). Отдельно показывать все фактически начисленные очки, включая 620–700. `milestones[].points` — пороги 100–600.
- `locked` означает закрытый день или недостигнутый порог. `in_progress` означает незавершённое задание, при истёкшем периоде и `acceptsProgress=false` показывать его как незавершённое без перехода. `claimable` означает «Забрать», `claimed` означает «Получено». Истечение таймера закрывает начисление очков и оставляет выдачу доступной.
- `reward` описывает полное содержимое приза. Для иконок и подписей использовать существующие `RewardArt` / `rewardText`. `hornRemaining` показывает невыданные заряды. Если `partiallyClaimed=true`, показывать остаток как отдельную кнопку «Забрать заряды». Если Рог полон, действие ведёт в действующее окно Рога. Сравнивать только фактически выданные значения из результата вызова.
- `gear` есть у финального порога. Для выбора передать одно из `gear.slots`. `gear.set`, `gear.level` и `gear.rarity` берутся из данных, уровень может вырасти до достижения порога. Названия слотов и редкости брать из `src/data/catalog.ts`, комплект из `src/saga/gear.ts`.

## Действия

Вызов `claimCarnivalReward(period.id, prize.id, slot?)` синхронно возвращает результат. Передавать IDs из текущего UI, включая `period.id` для приза прошлого месяца. Для обычных призов слот опускается.

| `status` | Реакция интерфейса |
| --- | --- |
| `claimed` | Показать выданное из `reward`; если есть `item`, показать его имя и место назначения `backpack` или `storage`. |
| `partial` | Показать выданное и остаток зарядов из обновлённого состояния. |
| `horn_full` | Показать «Рог полон. Потратьте заряды и вернитесь за призом». |
| `choose_slot` | Открыть выбор места экипировки. |
| `unavailable` | Обновить представление состояния. Обычный повторный тап возвращает этот статус. |
| `save_failed` | Показать «Приз не сохранён. Повторите попытку». |

Для «Перейти» у `campaign`, `farm`, `dungeon` использовать тот же `battle.startMode(route)`, что в «Приключениях». Для остальных маршрутов использовать `useGame.getState().open(route)`. При отсутствующем `route` переход не нужен. Для `dungeon` и `realm` показывать существующую стоимость входа там, где её показывает игровой режим. В карточке карнавала оставлять альтернативный вариант задания доступным.

Проверить переходы из карточек, повторный тап, возврат и состояние после перезагрузки. Проверить короткий WebView и 320/360/390/430 px, начальный день, закрытый день, границу 8-го числа, полный Рог, приз со склада и получение в новом месяце. Для ускорения в Playwright использовать подмену браузерного времени в изолированном профиле и обычные входы действий. Событие использует UTC-часы устройства. Если часы переведены на более ранний UTC-день, сохранённый период не открывается повторно.

## Баланс первого месяца

1–7 число UTC включительно. Окончание в 00:00 8-го числа. Пять заданий по 20 очков в день. Для 600 очков нужны 30 из 35 заданий. День 7 даёт ещё пять возможностей, а задания открытых дней можно доделывать до окончания события. Набор задач и призов определяет `src/saga/carnivalRules.ts`.

| Порог | Приз |
| --- | --- |
| 100 | Золото за 2 обычные победы над боссом для этапа старта + 4 заряда Рога |
| 200 | 10 Хаосита + 3 материала региона старта |
| 300 | 12 самоцветов + 6 зарядов Рога |
| 400 | Золото за 3 боссов + печать призыва + 2 осколка реликвии |
| 500 | 20 самоцветов + 5 материалов региона старта + 10 эссенции |
| 600 | 30 самоцветов + золото за 4 боссов + печать + эпическая часть регионального комплекта на выбор |

За закрытие отдельного задания выдаётся малый приз его дня. Золото и региональные материалы рассчитываются по этапу на старте периода. Уровень финального предмета фиксируется по уровню героя при достижении 600 очков плюс три. Получить предмет можно после окончания события по той же карточке.

Суммарно шесть порогов дают 62 самоцвета, 9 базовых выплат босса, 10 зарядов Рога, 10 Хаосита, 8 материалов, 10 эссенции, 2 печати и 2 осколка плюс предмет. Для первого этапа это 1350 золота порогов и до 380 золота заданий. Курс Рога в лавке составляет 1 самоцвет за заряд, одна печать стоит 20 самоцветов, вход в Логово или Царство — 5 Хаосита. Эти суммы дают две попытки в режиме с расходом Хаосита, два призыва и материалы для действующих улучшений. Самоцветы за пороги составляют около 21% от 300 самоцветов за 30 обычных ежедневных подарков по 10.

Доступный путь к финалу использует главу, бесплатный фарм, заряд Рога с естественным восстановлением, распыление и экипировку. Для испытаний Логова, Царства, Арены, дорогих улучшений, самоцветов и спутников в таблице есть доступные замены. Баланс сверялся с ценами и базовыми наградами игры.
