# VIKING VS ROME: LOOTBORN SAGA

**Новая отдельная игра** для Telegram Mini Apps. Задача — реализовать игровую механику Lootborn Warriors по детальному ТЗ владельца, а не вольно её переосмыслить. Главный экран — **строго по утверждённой картинке «100%»**. В игру добавляются персонажи владельца, выбранное оформление TERRITORY и проверенный режим Арены.

## Что уже подготовлено
ТЗ и инструкции. **Сам игровой код ещё не создан.** Три исходных ZIP-части с материалами 21 персонажа **уже загружены владельцем** в корень репозитория, они идентичны прежним проверенным ZIP из TERRITORY. Архив пока не распакован в новом проекте, 21 персонаж ещё не анимирован. Сам PNG 100%-экрана **пока не помещён в assets/references/** — его надо добавить отдельно.

## Чего не делаем без отдельной команды
Не трогаем репозиторий старой TERRITORY `territory-game-builde`, её Supabase, Telegram-бот, игроков, прогресс и текущие публикации. Для новой игры используются самостоятельные тестовые среды, отдельный сайт и отдельная конфигурация.
