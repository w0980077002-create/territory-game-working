### Сетевая Арена 1×1

Для локальной приёмки нужен Node.js 22.13+ и две независимые сессии браузера.

```sh
npm ci
npm run arena:build
npm run arena:local
```

Откройте [Алису](http://127.0.0.1:8787/?arenaLocal=alice) и [Бориса](http://127.0.0.1:8787/?arenaLocal=boris) в разных профилях браузера. В каждом откройте «Арена → Сетевая Арена 1×1 → Войти через Telegram → Найти соперника». Локальные учётные записи имитируют подписанный запуск Telegram и играют друг против друга через настоящий сервер. Локальный режим доступен на loopback. Для новой локальной базы задайте `ARENA_DB` с отдельным путём.

Сетевая Арена доступна в изолированной тренировочной сборке. Сервер выдаёт фиксированный уровень, рассчитывает силу по тренировочным комплектам и хранит тестовые очки отдельно. Предпросмотр Solo читает локального героя этой сборки. Для рейтинговых матчей нужен авторитетный серверный учёт приобретения и улучшения предметов, классов и навыков. GitHub Pages продолжает использовать обычную сборку Solo.

Для контейнерной проверки используется `scripts/qa/arena-container.sh`. Вне loopback процесс требует явный `ARENA_MODE=staging`, два или больше разрешённых тестовых ID и независимые ключи тестового окружения. Нынешняя задача разрешает локальную проверку и CI.
