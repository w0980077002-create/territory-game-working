# Две независимые версии ОДНОЙ новой игры для личного сравнения владельцем

**Решение владельца:** Claude Code и Codex получают одно и то же ТЗ и исходные материалы. Каждый самостоятельно создаёт свою полноценную версию **одной новой игры VIKING VS ROME: LOOTBORN SAGA**. Это не две отдельные игровые концепции и не работа над действующей TERRITORY.

- Claude Code пишет в ветке `claude-build` и предоставляет **свою работающую HTTPS-ссылку** на игру.
- Codex пишет в ветке `codex-build` и предоставляет **свою работающую HTTPS-ссылку** на игру.
- Оба исходят из одного состояния репозитория новой игры. Ветки Claude/Codex не смешивать. Не изменять `main`, ветку второго исполнителя и действующую TERRITORY (`territory-game-builde`); это другая игра, с отдельными данными и правилами.
- Ссылки должны открываться на телефоне; обновления каждой версии доступны по той же ссылке. Не выдавать GitHub, PR, ZIP или скриншот за ссылку на игру.
- **Никаких придуманных критериев, балльных оценок, промежуточных конкурсов и выбора победителя со стороны ассистента.** Владелец просто открывает обе версии VIKING VS ROME, играет и сам решает, какая ему лучше нравится.
- Полный объём утверждённого ТЗ сохраняется для обоих. Ни один исполнитель не сливает свою ветку в `main` без разрешения владельца.

**Единственный ожидаемый результат для сравнения: две разные игровые ссылки.**
